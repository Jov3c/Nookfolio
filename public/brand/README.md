# Nookfolio Logo

The **Quiet Nook** mark is an open architectural corner with one private dot. It represents a personal place on the web: calm, welcoming, and distinctly one's own.

| Nook Orange | `#EA632B` | 234, 99, 43   | 0, 58, 82, 8   | Primary brand field and accents    |

Pantone matching must be verified against a physical guide before print production.

## Usage

- Keep clear space around the mark equal to the diameter of its dot.
- Minimum digital size: 16 px for the small-size symbol; 24 px for the primary symbol.
- Use the orange app-icon version for favicons, avatars, and square placements.
- Use the black or orange transparent SVG for one-colour applications.
- Use the white version only on a dark or orange background.
- Do not stretch, rotate, add shadows, recolour individual parts, or place the mark on a busy image.

The website lockup intentionally combines the SVG symbol with live HTML text. This keeps the name accessible, responsive, and consistent with the site's typography without embedding a licensed font in the logo artwork.
